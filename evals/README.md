# evals

루프의 채점 기준. **에이전트는 이 폴더를 고칠 수 없다** (`.claude/hooks/protect.js`가 막는다).

## 둘 것

- `golden_{LOOP_NUM}.jsonl` — 골든셋. 한 줄에 질문 하나와 정답(통계표 ID, 기대 수치 등),매 루프 공격자 에이전트가 작성한다.
- `run_eval.py` — 골든셋으로 현재 코드를 채점하는 스크립트

## 출력 규칙

`loop/config.env`의 `EVAL_CMD`로 실행되며, **stdout 마지막 줄에 숫자 하나**(0~1, 클수록 좋음)를 출력한다.
그 위에는 무엇을 출력해도 되고, 실행 로그는 `loop/runs/iter-N.log`에 남는다.

```
... (세부 결과)
0.734
```

## 주의

- 골든셋은 학습·프롬프트 예시에 쓰지 않는다. 쓰면 점수가 오르는 것처럼 보일 뿐이다.
- 채점이 무작위면(LLM 판정 등) 시드를 고정하거나 여러 번 돌려 평균을 낸다. 점수가 흔들리면 루프가 우연을 개선으로 착각한다.
